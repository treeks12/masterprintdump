# MasterPrint Native Research Archive

This repository archives a failed attempt to build a native 1:1 replacement for Paulimaq MasterPrint / CadMapa.

The project remains useful as research material:

- Paulimaq `.ETQ` parser experiments and corpus tests.
- Paulimaq `.inf` / `layout.ini` layout parsing.
- Original CadMapa/MasterPrint UI and print reverse notes.
- WMF symbol identity work for textile care symbols.
- Documentation for a new clean label canvas/printer direction.

The recommended next product is not a CadMapa clone. See:

- `docs/new-label-canvas-printer-plan.md`
- `docs/masterprint-replica-plan.md`

Important conclusion: the new program should support all Paulimaq paper catalogs, with LNT-2 only as the first physical calibration gate.
